# 知识树 - 概念学习工具

欢迎使用知识树文档！

## 概述

知识树是一个基于AI的本地知识树生成工具，帮助用户构建和可视化复杂概念之间的关系。

## 主要功能

- 🖥️ **新建节点，选择Prompt，生成解释文档！**：方便至极，快速学习
- 🌳 **递归生成知识树**：选择疑惑点，继续生成，不断深入

## 快速开始

请查看 [关于页面](about.md) 了解更多信息。

## 技术栈

- **前端**：HTML5 + CSS3 + JavaScript
- **可视化**：vis-network
- **桌面应用**：Electron
- **后端**：Node.js + Express
- **AI接口**：DeepSeek API (支持R1推理模型和V3对话模型)
- **依赖管理**：npm
- **跨平台支持**：Node.js + Electron
